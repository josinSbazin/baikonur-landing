Как это работает

1. Проект и приложение

Структура: проект → приложения → билды.

2. Загрузка через CLI или консоль

Безопасная загрузка: временные ссылки и приватное хранилище.

3. Верификация и дистрибуция

Билд доступен только после проверки. Затем — ссылка или скачивание.

МЕСТО ПОД “HOW IT WORKS”:
3–4 скрина по шагам или короткое видео “Upload → Verify → Copy Link”

МЕСТО ПОД СКРИН “Members / Roles” или “Build list (Verified)”
(это лучше всего подкрепляет тезисы)

CLI, который встраивается в любой CI

Команда “одной кнопкой” из пайплайна: загрузить билд, добавить release notes, верифицировать и получить ссылку для тестеров. 

# пример сценария CI
uply login --token $UPLY_TOKEN
uply release create --project myproj --app ios --file build.ipa --notes "Fix login crash"
uply release verify --project myproj --app ios --build-key 
uply release link --project myproj --app ios --build-key  --type download

(Здесь можно заменить на реальные команды CLI, когда вы стабилизируете названия.)
